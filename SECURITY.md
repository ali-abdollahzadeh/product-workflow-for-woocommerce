# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.2.x   | :white_check_mark: |
| < 1.2   | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability within Product Workflow for WooCommerce, please do not open a public issue.

Instead, please send an email to **aliab.dev@gmail.com** (or reach out via [aliabdollahzadeh.dev](https://aliabdollahzadeh.dev/)).

Please provide:
- A clear description of the vulnerability.
- Steps or proof-of-concept scripts to reproduce the issue.
- The environment details (WordPress version, WooCommerce version, PHP version).

You will receive an acknowledgment within 48 hours, followed by updates on the fix and coordinated disclosure.
